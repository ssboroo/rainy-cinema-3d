# RAINY CINEMA 3D

A 3D cinema seat-selection starter built with React, Vite, Three.js and React Three Fiber.

## Status

This repository currently contains the visual prototype only. Seat inventory and booking are demo data; no real reservation or payment is created.

## Requirements

- Node.js 20.19+ or 22.12+
- npm

## Development

```bash
npm install
npm run dev
```

## Validation

```bash
npm test
npm run build
```

See [ROADMAP](docs/ROADMAP.md) for the production implementation plan. Never expose private cinema-provider or payment credentials in browser code.
